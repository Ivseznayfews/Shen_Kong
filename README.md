- 1.2.3 已发布至 [Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3836219050)，用户已进行游戏内测试。
- 1.2.4 是开发测试版，优化自动刷新时的定位标记保留；该改动尚待游戏内验证。
- 游戏目标版本：0.46D；构建需要本机游戏的托管程序集，不包含游戏 DLL。

`BedCheck` 为当前源码，`BedCheck.Tests` 为规则测试，`releases` 存放按版本整理的模组文件。
